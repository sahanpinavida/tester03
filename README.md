# SimpleCal

A simple web-based calculator for basic arithmetic operations (addition and subtraction). Built with HTML, CSS, and vanilla JavaScript, running entirely client-side with no external dependencies.

## Setup

1. Clone or download the repository
2. No build process or dependencies required
3. Open src/index.html directly in a web browser, or serve via any static web server

## Usage

Open src/index.html in your browser or serve the project via any static web server.
